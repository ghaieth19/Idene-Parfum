## 🔄 Flux Utilisateur

```
Visiteur arrive sur le site
         │
         ▼
    Page /accueil
         │
         ├─→ Scroll et découverte
         │   ├─→ Hero (stats animées)
         │   ├─→ Avantages
         │   ├─→ Catalogue (filtre/recherche)
         │   │   └─→ Clic produit → Quick View
         │   ├─→ Collections
         │   ├─→ Comment ça marche
         │   ├─→ Témoignages
         │   └─→ CTA Banner
         │
         ├─→ Clic "Demander un accès"
         │   └─→ Redirige vers /auth
         │
         ├─→ Clic "Connexion"
         │   └─→ Redirige vers /auth
         │
         └─→ Clic "Ajouter au panier"
             └─→ Alert: "Connectez-vous"
                 └─→ Redirige vers /auth
```

```

├── Grilles 2 colonnes

├── Hero responsive
└── Footer 2 colonnes

> 968px (Desktop)
├── Layout complet
├── Menu horizontal
├── Grilles 3-4 colonnes
```
